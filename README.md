# Elyms

曳尔沐 / Y 桌宠，现正式版 **2.1.0**，由 Beta 2.1 转正。

[下载最新正式版](https://github.com/MalricAurelianVale/Elyms-releases/releases/latest) · [2.1.0 累计更新说明](RELEASE_NOTES-2.1.0.md) · [完整使用与升级步骤](USAGE-2.1.0.txt)

推荐下载 **Elyms-2.1.0-pure.zip**，解压到固定文件夹，退出旧桌宠，再打开里面的 **Elyms.exe**。包内含详细说明与第三方声明。需要64位 Windows 和 Microsoft Edge WebView2 Runtime。

普通桌宠、角色切换、内置待机语音、游戏模式、音乐播放不需要配置 AI。支持 QQ 音乐、网易云、酷狗、本地音频、独立本地收藏、预览导入、队列和迷你播放器；平台播放仍受网络、账号权限与服务接口影响。

“对话与陪伴”可自行配置模型 API，选择文字对话、读屏和自动陪伴。启用读屏会将所选桌面内容发送给自己配置的服务商。**pure 不提供密钥、账号、私人资料、ONNX 模型、Python 运行库或 FFmpeg**。AI 回复朗读可选用独立 ONNX 包；它与程序已内置的待机语音不同。

正式版覆盖升级继续读取原正式版配置。Beta 和正式版个人目录分开，迁移前请按说明备份并退出所有桌宠，不会自动覆盖已有正式版资料。移动 EXE 后请重新关闭、开启自启动。

`Elyms.exe` 附件与 pure 包中的程序相同，供单独升级下载。更新说明累计自上次公开版 1.1.6，包括未公开的1.1.7修复及Beta阶段功能。

本仓库用于公开说明与二进制分发，开发源码保留本地。历史版本仍可在 Releases 中下载。
