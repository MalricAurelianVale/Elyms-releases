Elyms 2.1.0 正式版 pure：从解压到使用

【本包里有什么】
Elyms.exe 是启动程序。内置角色、动画、预录待机语音与音乐功能。
使用说明.txt 是本说明；更新说明.md 是自上次公开版 1.1.6 起累计的更新。
THIRD_PARTY_NOTICES.md 是第三方声明。
pure 不包含任何人的 API Key、账号、个人歌单、缓存；也不包含 ONNX 模型、Python 运行库或 FFmpeg。普通桌宠和内置语音不需要这些模型。

一、先启动起来
1. 如果旧正式版或 Beta 正在运行，在任务栏右下角的小图标上右键，选择“退出应用”。只关设置面板不算退出。图标藏起来时点通知区小箭头。
2. 右键 Elyms-2.1.0-pure.zip，选“全部解压缩”，解压到一个固定位置，例如 D:\桌宠\Elyms-2.1.0。不要从压缩包预览窗口启动。
3. 打开解压后的文件夹，双击 Elyms.exe。隐藏了扩展名时，认准 Elyms、类型“应用程序”。Windows 请求管理员权限时，核对是自己刚打开的程序再允许。
4. 桌宠出现后，右键桌宠或通知区图标打开设置。面板应显示 Elyms 2.1.0。显示旧版本，说明启动了旧文件或旧进程还在。
5. 面向64位 Windows，需 Microsoft Edge WebView2 Runtime。缺少运行库时，从微软官方页面安装 Evergreen Runtime（64位选 x64）：https://developer.microsoft.com/microsoft-edge/webview2/
6. 看不到桌宠先看是否隐藏；默认 F9 切换隐藏。看得见但点不到，检查游戏模式；默认 F7 切换。改过的快捷键以设置为准。通知区入口仍可打开面板。

二、正式版覆盖升级
1. 退出旧正式版。可以先保留旧 EXE，改名为带旧版本的名字作留档。
2. 用新包的 Elyms.exe 替换原位置的 Elyms.exe，再启动。正式版个人设置仍读取原目录，不在压缩包中。
3. 若换了程序位置，先关闭再开启“开机自动启动”，让启动项指向新位置。
4. 自启动可选择延后申请管理员权限，默认关闭，修改后保存用户选择。主动双击仍按管理员路径运行；自启动过渡与主动启动不是同一个入口。
5. 正式版和 Beta 的应用身份分开；不要同时打开两个版本来判断某个设置是否生效。

三、从 Beta 搬个人资料（可选；已有正式版数据不会自动覆盖）
只想全新使用可以跳过。以下操作只在自己的电脑做，不要把复制后的目录分享出去。
1. 退出 Beta 和正式版的所有进程。
2. 按 Windows 键 + R，输入 %APPDATA% 并回车。找到 com.example.elyms.beta，这是 Beta 的设置目录；com.example.wuwapet 是正式版目录。
3. 先分别复制这两个目录，在自己电脑的安全位置保留完整备份，例如桌面“Elyms个人备份”。备份含私人资料，不要上传公开仓库或网盘分享。
4. 正式版目录不存在时，先启动正式版一次再退出，然后回到此处。
5. 从 Beta 目录复制下面确实存在且你需要的文件到正式版目录。覆盖同名文件会换掉正式版对应设置，不想换就跳过：
   pet-preferences.json、appearance.json、taskbar-icon.json（桌宠设置、外观与任务栏图标）
   companion.json（陪伴接口与人格设置）
   reply-voice.json（朗读设置）
   audio-policy.json（声音设置）
   music.json、music-library.json、music-player.json、music-import-previews.json、music-recovery.json、music-resolution.json、music-loudness.json、music-hotkeys.json（音乐选项、集合、队列、预览、失败恢复、替代音源、响度与快捷键，存在时复制）
6. 要保留同一 Windows 用户下已保存的接口密钥 / 音乐登录，也可复制 Beta 的 secrets 文件夹到正式版。它包含加密私人凭据，只适用于原 Windows 用户；换电脑 / 换 Windows 账号可能无法解密，需要重新登录和填写 Key。不想迁移凭据就跳过并重新登录。
7. 不要把整个 WebView2 浏览器缓存目录覆盖过去，也不用复制日志和音乐缓存。自启动注册单独处理，不靠这些 JSON 搬迁；请在正式版重新开关自启动。
8. 启动正式版，检查角色、接口、音乐集合和朗读路径。若选错资料，退出后从第3步备份恢复对应文件。

四、待机与预录语音
1. 在设置里打开“桌宠语音”。睡醒、看手机、闲聊各有5条，会轮流使用，冲突语音不排队。
2. “待机活动间隔”可选预设或自定义。自定义单位为分钟，仅支持整数或半分钟，例如0.5、1、1.5、6；填写后点保存。
3. 旧版7秒等设置不会被自动改成半分钟，界面会提示旧值。想继续保留就不修改，填写新值后按新分钟数运行。
4. Y 默认只有无声睡觉待机；需要借用曳尔沐闲聊 / 睡醒语音时，切到Y后主动打开对应选项。切换角色会重新计时。

五、AI 对话、读屏与自动陪伴
只用普通桌宠 / 音乐可跳过；AI 服务商通常另行收费，本包不赠 Key。
1. 从功能面板左侧打开“对话与陪伴”。选自己的服务商预设，填自己的 API Key，再选择该服务商实际提供的模型。自定义接口应为兼容接口地址。
2. 先点连接测试或发送一句短对话。测试通过后，按界面保存 / 应用设置。以后在同一 Windows 用户下会保存，不必每次填写。
3. 首次成功配置会默认启用读屏陪伴，按自己的需要调整自动陪伴、读屏开关和间隔。已经改过的选择会保留。
4. 读屏会把选择的桌面内容发送给自己配置的服务商；不想发送桌面就关读屏，仍可文字对话。若模型不支持图片，选择视觉模型或关闭读屏。
5. 默认回复偏短，适合自动陪伴。需要长解释时明确要求详细回答；长回复可能仅显示文字，不进行本地朗读。
6. 换服务商后要使用对应 Key，不要把一个平台的密钥提交到其他平台。密钥不应发给别人或放进截图。

六、可选 ONNX 生成回复朗读（和内置待机语音不同）
1. pure 内没有生成模型。已有 Beta ONNX 包可以复用，不需要重新准备14GB训练环境；没有语音包也不影响文字对话、预录待机语音与音乐。
2. 将自己已有且完整的 Elyms-Voice-Runtime 和 voice-packs 文件夹放在 EXE 同一文件夹。应能看到 Elyms-Voice-Runtime\python.exe、voice-packs\Elyms-ONNX\manifest.json、voice-packs\common-v2pro\manifest.json。
3. “对话与陪伴 → 回复朗读”点击“使用随包 ONNX（推荐）”。这里的“随包”表示检查你放在程序旁边的可选文件，不表示 pure 自带模型。
4. 找不到时手动填文件夹完整路径：运行库选 Elyms-Voice-Runtime，语音包选 voice-packs\Elyms-ONNX。不是选择 python.exe 文件。勾选启用，应用朗读设置，再点试听。
5. 也可以直接选原 Beta 文件夹中的这两个目录。不要删除它们，否则正式版也会找不到模型。
6. 初次加载约需十几秒，慢电脑会更久。新文本要整条生成好再连续播放，本机短句曾测试约7.7—10秒，不是即时开口。
7. 生成会额外使用数GB内存；冷加载需约6GiB可用物理内存。游戏内存近满时可能跳过本次生成，文字仍可见。可点“停止并释放模型”。
8. 超过160字的长回复只显示文字，不偷偷截去后半句。先让桌宠简短表达即可。

七、音乐：登录、搜索与导入
1. 打开“音乐”，在“搜索与导入来源”选QQ音乐、网易云或酷狗。进“账号与设置”使用对应平台的官方授权入口登录，按窗口提示扫码 / 授权，不需要手抄Cookie。
2. 各平台分别保留一个活动账号，切换来源不退出其他平台；同一平台换号先退出再登录。已导入本地集合和本地收藏会保留。
3. 在“发现”输入歌名，搜索后核对歌名、歌手，点“现在播放”。点“加入队尾”则排到现有队列末尾；空队列会按界面提示开始。
4. “音乐库 → 导入音乐 → XX音乐账号收藏”先读取预览。每页10首，可跨页勾选，排除不要的曲目，排错可以恢复；再点导入全部已选或合并全部未排除项。
5. 也能读取账号歌单、填写公开歌单链接 / ID，或扫描本地音频文件 / 文件夹。读取是预览，应用才写入本地集合；平时优先合并，替换会明确确认。
6. 本地歌曲不要移动 / 删除原文件；云端曲目要有可用网络与相应播放权限。VIP / 版权限制不会因为登录而必然消失。
7. “更多”里可加到本地收藏、下一首播或指定替代音源。本地收藏只存在桌宠中，不修改云端。
8. 队列支持移动 / 移除 / 恢复。进入队列时显示当前曲目所在页。上一页 / 下一页或输入页码可以浏览其他页。
9. “重新载入已保存列表”只刷新本地显示；“查看来源更新”先展示预览。移除 / 替换等操作可使用相应恢复入口，恢复数量有限，不等于永久备份。

八、播放入口、声音与故障
1. 底部播放器支持暂停、继续、上下首、进度和0—100音量输入。右键桌宠的音乐菜单也有快捷控制。
2. 点击桌宠展开气泡扇后，右耳边缘音符可打开迷你播放器。暂停 / 停止时也可使用；气泡扇收起、隐藏或游戏穿透时该热区关闭。通知区菜单仍可操作。
3. “账号与设置 → 声音与响度”可独立调语音音量、开启音乐播放时暂停桌宠语音；暂停音乐后不会补播刚才积压的语音。
4. 可选响度均衡与备用解码需要自备 FFmpeg。已有媒体工具包可把 tools\ffmpeg.exe 放到 EXE 旁，或填写已有工具的完整路径。pure 不包含该工具。
5. 每首录音原始响度可能不同；首次尚未测量时会先按原音量播放，响度均衡也不意味着所有录音听感完全一致。
6. 播放失败先尝试“重试原曲”。需要时主动开启严格同曲换源，或用“更多 → 指定替代音源…”选择正确录音。替代来源不会改变原收藏身份。
7. 连续三首最终失败会停止，避免整个队列被刷空。网络、VPN、账号权限或平台接口都可能影响结果；可先关闭故障代理测试，不要反复覆盖个人库。
8. 需要反馈时，从设置点“打开日志目录”，保留相关时间、歌曲、平台、操作顺序和截图。日志中 music-events.jsonl 有队列 / 取流事件。不要公开 secrets 文件夹、Cookie 或 API Key。

九、更新、卸载与个人资料
1. 设置的“检查更新”使用正式发布仓库；GitHub失败会尝试备用版本信息。下载链接仍交给浏览器打开官方附件，退出程序后手动替换。
2. 删除 EXE 不等于删除个人资料。正式版位于 %APPDATA%\com.example.wuwapet，Beta位于 %APPDATA%\com.example.elyms.beta；缓存另在 %LOCALAPPDATA% 对应目录。
3. 想停用，先关闭自启动并退出，再删除不用的程序文件。个人资料请先备份后自行决定，勿误删旧版本留档、自己训练的模型或原音乐文件。
